# Flee plan command

Apply the `planning-method` skill in full.

1. Clarify an observable outcome, the reason it matters, and hard constraints. Ask one sharp question if the goal is unclear.
2. Confirm real capacity: work-block length, available days, deadlines, and fixed commitments.
3. Decompose into milestones with definitions of done and verb-first, session-sized actions. Turn unknowns into research actions.
4. Identify the critical path.
5. Confirm the user's working folder, then create or update `plan-<short-name>.md` using the planning-method template.
6. Summarize the plan, state one next action, and offer `$flee-schedule` or `$flee-next`.

Keep plan content local. De-identify external queries and obtain confirmation before sending sensitive information outside the machine.
